# Knowledge Base: Customer Support

## Overview
This knowledge base provides common guidance for handling customer support requests.

## Common Issues

### Password Reset
Users can reset their password from the login page using the **Forgot Password** option. A reset link is sent to the registered email address.

### Account Access
If a user cannot access their account:
1. Confirm the email address.
2. Check whether the account is active.
3. Ask the user to reset their password if necessary.
4. Escalate persistent login failures to technical support.

### Billing Questions
For billing-related questions, verify the invoice, payment status, and subscription plan before making changes.

## Escalation
Escalate issues involving security, suspected unauthorized access, failed payments that cannot be resolved, or repeated technical failures.

## Best Practices
- Do not request or store passwords.
- Verify account ownership before sharing sensitive information.
- Keep responses concise and clear.
- Record important support actions.
